# **App Name**: Finovate

## Core Features:

- Smart Budget Tracker: Automatically categorize user transactions (manual or synced via Plaid/TrueLayer) using a Cloud Function that employs a simple ML tool or predefined rules to categorize transactions and track spending.
- Virtual Savings Wallet: Allow users to create virtual wallets, set savings goals, and deposit/withdraw virtual funds, potentially linking to real accounts via a third-party payment provider.
- Level-Up System: Implement an XP and level-up system where users earn XP for various actions (deposits, quest completion) and unlock badges, themes, and other rewards.
- Behavior Nudges: Provide personalized nudges based on spending patterns to encourage better financial habits, potentially scheduling local/push notifications and linking to micro-lessons.
- Finance Quests: Offer quests with progress tracking and XP rewards for completing specific financial tasks.
- Community Challenges: Enable users to join challenges, invite friends, and track group progress.
- Mood-Based Insights: Prompt users to log their mood after purchases and show correlation charts between spending and emotions, aided by a small analytics function to produce insights.

## Style Guidelines:

- App background: Dark background (#0C0C0C) to provide contrast and modernity.
- Primary gradient: Linear gradient (#1B188A to #35258B) for buttons and progress fills, symbolizing innovation.
- Accent color: A warm, golden-brown (#7C561F) accent to highlight rewards and achievements, adding a touch of richness.
- Body and headline font: 'Poppins' sans-serif font for all UI elements, offering a clean and tech-forward aesthetic.
- Neon outlined icons with soft shadows to match the futuristic headings requested.
- Glass card components using CSS backdrop-filter for a frosted glass effect.
- Microinteractions such as coin animations on deposits and confetti on level up to enhance user engagement.
